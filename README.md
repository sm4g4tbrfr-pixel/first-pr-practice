# first-pr-practice

Claude Code と一緒に、初めてのGitHub PR(プルリクエスト)フローを練習するためのリポジトリです。

## これは何か

- git / GitHub の基本的な流れ(init → commit → push → PR)を試すための練習用リポジトリです
- 会社の機密情報は含まれていません

## 使い方

1. ブランチを作成する: `git checkout -b <branch-name>`
2. 変更してコミットする: `git commit -m "説明"`
3. プッシュしてPRを作成する: `git push -u origin <branch-name>` → `gh pr create`
